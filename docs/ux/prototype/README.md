# ThoughtTree prototype (reference)

A throwaway, clickable HTML prototype of the phone UX that the owner tried and changed on their phone (state of 2026-11-13). Open `thoughttree-prototype.html` in a browser; it stores its example data only in the browser.

- Screenshots of key screens: `1-tree.png`, `2-item-menu.png`, `3-detail.png`, `4-capture.png` (iPhone size, light mode)
- Reference only: where the prototype and [ux-concept.md](../../ux-concept.md) differ, the concept wins; behaviour of the prototype becomes binding only once it is recorded as a decision there
- Prototype-only parts (local storage, event log view, reset, the "Prototype" label) are not product behaviour

# ThoughtTree prototypes (reference)

Throwaway, clickable HTML prototypes of the phone UX. Open them in a browser; they keep their example data only in the browser.

- **`thoughttree-prototype-2.html` (current reference, state of 2026-11-13):** the owner's prototype adapted to the decisions up to D-105 (several trees with the tutorial as its own tree, Move to… with position, tag suggestions, one action one undo step, capture while typing, Deep stone inbox, importing a tree as a branch, latest changes with "By time"). Screenshots: `v2-1-tree.png`, `v2-2-item-menu.png`, `v2-3-detail.png`, `v2-4-capture.png`
- `thoughttree-prototype.html`: the owner's first version as tried on their phone, with screenshots `1-tree.png` … `4-capture.png`; its comparison with the decisions is in [review.md](review.md)
- Not built in prototype 2: drag and drop and sort mode (D-88, D-89), switching trees inside the capture sheet, the conflict view, Links and views
- Reference only: where a prototype and [ux-concept.md](../../ux-concept.md) differ, the concept wins; behaviour becomes binding only once it is recorded as a decision there
- Prototype-only parts (local storage, event log view, reset, the "Prototype" label, plain-text exchange) are not product behaviour

Readable import and export

Exporting a tree or a branch as readable files (Obsidian, Markdown, OPML, JSON) and bringing files back in, as a new tree or into a thought. Rules already decided: a readable export is never automatic and needs a confirmed warning, the file name says "unencrypted" (ADR-019); re-importing files that carry ids updates the thoughts they came from (ADR-078); a branch is exported and imported from the thought's menu (ADR-080); a whole tree from More › Trees and the tree list (D-179). Phone, Paper theme, example content only.

Tags and relation types as thoughts

Since ADR-082 and ADR-084, tags and relation types are thoughts in two marked branches of every tree, "Tags" and "Relation types". A tag's note is its description and its nested tags are thoughts inside it; a type's note says what it means, and it has a reverse name and can be the same in both directions. A new tree has only the type "related". This sketch shows where the two branches live (D-177), how a tag and a type look as a page, and what changes for chips, joining and copying (D-178). Phone first, Paper theme, example content only.

A tag is a thought: its title is the name (renaming it is editing the title, for every thought at once), its note the description, its children the nested tags. Below them, the thoughts that carry it, with a link to the filtered outline (D-14). Its ⋯ has the usual item menu; Delete removes the tag from every thought, undoable, and the history keeps it.

Headings in notes, and the page “This tree”

"Headings become thoughts" is a tree feature, on by default (ADR-079). On, a heading typed in a note becomes a thought inside (D-155). Off, notes keep their headings, as Zettelkasten notes from Obsidian do. This sketch shows where the switch lives (More › This tree…, D-183), how Focus tells a heading in a note from a thought shown as a heading when the feature is off, and what the one-document Markdown export does with them. Phone, Paper theme, example content only.

6 · One Markdown document: what headings in notes become (D-185, provisional)

# Spaced repetition

Review at growing intervals: a day, three days, a week.

**Why it works**

Each review comes just before forgetting, so recall is effortful.

**Where it fails**

Facts without connections fade anyway.

## Leitner boxes

Cards move up a box when remembered.

## Interleaving

The one-document Markdown export writes thoughts as headings (ADR-072). Headings inside notes would look the same and come back as thoughts, so this sketch writes them as bold lines: the document reads well and a re-import keeps them in the note. The Obsidian form (one file per thought) keeps note headings exactly as they are. Alternative: write them one level deeper as real headings, which reads more like a document but turns them into thoughts on re-import.

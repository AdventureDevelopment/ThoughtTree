Beta: an update that changes the format

Before release 1, an update may change how ThoughtTree stores thoughts (ADR-085). Then the app tells the tester before updating, offers to export every tree in the Obsidian form, waits for the answer (ADR-036), keeps the old data untouched, shows old trees as not readable, and offers to import the export as new trees. The promise is "kept as far as possible", never more. Phone, Paper theme, example content only.

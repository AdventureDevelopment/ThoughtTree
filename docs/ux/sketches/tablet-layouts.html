Tablet and desktop: using the wider screen

Tablet in landscape, Paper theme, with the decisions so far (bottom bar, 📥, faint feedback bubble, detail strip with ↗ ↙). The same layouts would serve the desktop. Example content only. On narrow phones everything stays one column.

A · One column, like the phone

The outline takes the full width; Open shows the detail page as its own screen. Nothing new to learn, but much empty width on a wide screen.

B · Outline and detail side by side

Selecting a row shows its detail on the right, live: note, tags, links, history. The outline stays visible while you read or write the note. In portrait, or in a narrow window, it falls back to A.
